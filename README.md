# Student Study Analysis 📊

## 📌 Project Overview
This project analyzes student study habits and academic performance using Python. It explores the relationship between daily study hours and exam marks, summarizes student results, and visualizes the findings using a scatter plot.

## 🎯 Objectives
- Analyze student study hours, attendance, and exam marks.
- Calculate average marks and pass percentage.
- Identify the top-performing student.
- Examine the correlation between study hours and marks.
- Visualize the relationship between study hours and exam marks.
- Export student data to a CSV file.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib

## 📂 Project Files
- `student_study_analysis.py` — Python source code.
- `study_hours_vs_marks.png` — Scatter plot generated by the program.
- `student_study_data.csv` — Exported student dataset.
- `README.md` — Project documentation.

## ⚙️ How to Run
1. Install Python on your computer.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib
   ```

3. Run the Python file:

   ```bash
   python student_study_analysis.py
   ```

4. Check the terminal for the analysis summary.
5. Open `study_hours_vs_marks.png` to view the graph.
6. Open `student_study_data.csv` to view the exported dataset.

## 📈 Analysis Performed
- Total number of students
- Average exam marks
- Number of students who passed
- Pass percentage, using 40 marks as the passing threshold
- Highest-scoring student
- Correlation between study hours and marks

## 💡 Key Learning Outcomes
- Working with Pandas DataFrames.
- Calculating statistics from structured data.
- Using correlation to explore relationships between variables.
- Creating visualizations with Matplotlib.
- Exporting data to CSV format.
